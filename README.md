# Caderno Temático: Aprendizagem Kali Linux Passo a Passo com NotebookLM 🧠

## 📋 Contexto e Objetivos
Este projeto foi desenvolvido como parte do desafio prático da DIO (Digital Innovation One). O objetivo principal é utilizar a Inteligência Artificial do Google NotebookLM como uma ferramenta de aprendizagem ativa, aplicando pensamento crítico, curadoria de conteúdo e engenharia de prompts.

*   **Tema Escolhido:** Assistente AI Kali Linux.
*   **Objetivo de Estudo:** Compreender o funcionamento do ecossistema Kali Linux, aprender a utilizar seus comandos básicos e orientar o uso passo a passo de suas ferramentas nativas de segurança e auditoria.

### 📕 Glossário de Conceitos Baseados na Documentação
*   **Kali Undercover:** Um script nativo do Kali Linux que altera instantaneamente o tema visual do sistema para parecer com o Windows 10, permitindo o uso discreto em locais públicos.
*   **Kali NetHunter:** A plataforma de testes de invasão e segurança voltada para dispositivos Android, permitindo simular ataques a redes sem fio diretamente de um smartphone compatível.
*   **Credenciais Padrão:** Desde a versão 2020.1, o Kali Linux aboliu o usuário `root` por padrão durante a instalação. O novo usuário padrão e senha de sistema configurados de fábrica passaram a ser `kali` / `kali`.
*   **Arquitetura ARM:** Versões customizadas do Kali criadas especificamente para rodar em hardwares embarcados e de baixo consumo de energia, como o Raspberry Pi.
