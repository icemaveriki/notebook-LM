# Caderno Temático: IA Aprendizagem kali Linux passo a passo com NotebookLM 🧠

## 📋 Contexto e Objetivos
Este projeto foi desenvolvido como parte do desafio prático da DIO (Digital Innovation One). O objetivo principal é utilizar a Inteligência Artificial do Google NotebookLM como uma ferramenta de aprendizagem ativa, aplicando pensamento crítico e curadoria de conteúdo.

*   **Tema Escolhido:** Assistente AI Kali Linux
*   **Objetivo de Estudo:** atuar e ajudar usar comandos Kali e orientar o uso de suas ferramentas passo a passos.
